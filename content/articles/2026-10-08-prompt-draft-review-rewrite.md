## こんなときに使う

- お客様向けのお知らせ、社外メール、プレスリリースの下書きをAIに作らせている
- 「AIに書かせると、なんとなくそれっぽいけど、どこか惜しい」と感じる
- 「もっと良くして」と頼むと、良かった部分まで書き換えられてしまう
- 上司やチームで、文書の「合格ライン」をそろえたい

1回のお願いで完ぺきな文章を出させるのは、むずかしいです。そこで、人が文章を仕上げるときと同じように、<strong>「下書きを作る」「採点する」「悪いところだけ直す」</strong>の3段階に分けてAIに頼みます。

この記事は**上級**です。複数のプロンプトを順番に使う流れを組み立てて、採点の基準（採点表）を自分で作れる人に向けています。ChatGPT・Gemini・Claude・Copilot のどれでも使えます。

## まず「採点表」を作る

この方法のいちばん大事な部分は、**採点表を自分で作ること**です。AIに「良い文章か見て」と頼むだけだと、AIは何を基準にすればいいか分かりません。結果として、あいまいなほめ言葉が返ってきます。

基本の5項目は次のとおりです。「5点の状態」を、自分の会社の文書に合わせて書きかえてください。

| 項目 | 見るところ | 5点の状態（例） |
|---|---|---|
| 正確さ | 事実の入れもれ・付け足し | 渡した事実がすべて入り、それ以外の事実を足していない |
| 読み手 | 相手に合った書き方か | 読み手が1回読んで、自分が何をすればいいか分かる |
| トーン | 言葉づかい・温度感 | 丁寧で落ち着いている。おわびや感謝がくどくない |
| 禁止表現 | 使ってはいけない言葉 | 社内で決めたNGワードが1つも入っていない |
| 長さ | 量とむだ | 決めた字数におさまり、同じことをくり返していない |

ポイントは、<strong>「5点の状態」を具体的な文で書く</strong>ことです。「分かりやすい」ではなく「ITに詳しくない人が1回読んで分かる」のように書くと、AIの採点がぶれにくくなります。

## プロンプト（コピーして使えます）

3つのプロンプトを、**同じチャットの中で順番に**送ってください。`【 】` の部分は、自分の文書に合わせて書きかえます。

### ステップ1：条件をはっきり決めて「作る」

```
あなたは【会社名】の【広報担当】です。次の条件で【お客様向けのお知らせ】の下書きを作ってください。

# 目的
【例）システムメンテナンスのため、Web予約が一時止まることを伝える】

# 読み手
【例）サービスを使っている個人のお客様。ITに詳しくない人も多い】

# 必ず入れる事実（これ以外の事実は書かない）
- 【日時：2026年10月20日（火）22:00〜翌2:00】
- 【止まるもの：Webでの予約受付】
- 【問い合わせ先：お客様窓口 0120-XXX-XXX】

# 条件
- トーン：【丁寧で落ち着いた文面。おわびは1回だけ】
- 長さ：【400字以内】
- 使わない言葉：【「させていただきます」を何度も使う／「絶対」「必ず」】
- 事実が足りないところは推測で埋めず【要確認】と書く
```

### ステップ2：採点表で「採点する」

```
今書いた下書きを、次の採点表で厳しめに採点してください。まだ書き直さないでください。

# 採点表（各5点満点）
| 項目 | 5点の状態 |
|---|---|
| 正確さ | 「必ず入れる事実」がすべて入り、それ以外の事実を足していない |
| 読み手 | 【ITに詳しくない人】が1回読んで、自分が何をすればいいか分かる |
| トーン | 【丁寧で落ち着いている。おわびは1回だけ】 |
| 禁止表現 | 「使わない言葉」が1つも入っていない |
| 長さ | 【400字以内】で、同じことをくり返していない |

# 出し方
- 「項目｜点数｜理由｜気になる箇所（本文から引用）」の表にする
- 理由は1〜2文。ほめ言葉はいらない
- 4点以下の項目には、具体的な直し方を1つずつ書く
- 最後に合計点（25点満点）を書く
```

### ステップ3：低い点だけ「直す」

```
採点で4点以下だった項目だけを直してください。

# 直し方のルール
- 5点だった項目にかかわる部分は変えない
- 「必ず入れる事実」の日付・数字・名前は変えない
- 新しい事実を足さない

# 出し方
1. 変更点の一覧：「直す前 → 直した後（どの項目のためか）」を箇条書きで
2. 直した後の全文
3. 直した後の文章を、同じ採点表でもう一度採点した表
```

ステップ3の最後の採点で、まだ4点以下の項目が残っていたら、ステップ3をもう1回だけ送ります。何回もくり返すと、文章がかえって不自然になりやすいので、**やり直しは1〜2回まで**にしておきましょう。

## 使ってみるとこうなる（例）

メンテナンスのお知らせで試すと、ステップ2ではたとえば次のような表が返ってきます（内容はイメージです）。

| 項目 | 点数 | 理由 |
|---|---|---|
| 正確さ | 5 | 3つの事実がすべて入っている |
| 読み手 | 3 | 「その間はどうすればいいか」が書かれていない |
| トーン | 4 | おわびが冒頭と最後の2回ある |
| 禁止表現 | 3 | 「させていただきます」が3回続いている |
| 長さ | 5 | 約350字でおさまっている |

ステップ3では、低い点の項目だけが直り、次のような変更点の一覧が出ます。

- 「ご迷惑をおかけし、誠に申し訳ございません（最後の段落）」→ 削除（トーン：おわびを1回に）
- 「メンテナンスを実施させていただきます」→「メンテナンスを行います」（禁止表現）
- （追加）「この時間にご予約の方は、お電話でも受け付けます【要確認】」（読み手：その間の行動を示す）

3つ目のように、AIが「新しい案内」を足そうとすることがあります。<strong>【要確認】</strong>が付いた部分は、本当にその対応ができるかを社内で確かめてから残してください。

## うまくいくコツ

- **ステップを分けて送る**：「作って、採点して、直して」を1回で頼むと、採点が甘くなりがちです。1つずつ送ると、それぞれの作業に集中してくれます。
- <strong>「まだ書き直さないで」と書く</strong>：採点の段階で勝手に直されると、何がどう変わったか追えなくなります。
- **直す前と後を並べさせる**：変更点の一覧があると、人が確認する時間がぐっと短くなります。全文を読み比べる必要がありません。
- **採点は別のチャットでもできる**：自分で書いた文章には甘くなりやすいので、下書きを新しいチャットや別のAIツールに貼って、ステップ2だけ頼むのも効果的です。

## 採点表を保存して使い回す

一度作った採点表は、毎回書かなくてすむように保存しておきましょう。

1. ステップ2のプロンプトを、メモ帳や社内の共有フォルダに「社外文書の採点表」として保存する
2. 文書の種類ごとに「5点の状態」を少し変えた版を作る（例：お客様向けのお知らせ用、取引先へのメール用、プレスリリース用）
3. よく使う場合は、AIツールの「カスタム指示」や、指示と資料をまとめておける「プロジェクト」のような機能に採点表を入れておく。チームで同じ場所を使えば、全員が同じ基準で文書を見られます

採点表の「禁止表現」の欄に、社内で過去に問題になった言い回しを足していくと、使うほど会社に合った採点表に育っていきます。

## 気をつけること

- **AIの採点は「完ぺきな審査」ではありません**。AIは自分の書いた文章に甘くなることがあります。点数は「どこを直すと良くなるか」の目安として使ってください。
- **事実の正しさはAIには確かめられません**。日付・金額・電話番号・商品名などは、元の資料と人が1つずつ照らし合わせてください。確認のしかたは[AIの「もっともらしいウソ」を見抜く3つのチェック](/articles/2026-10-06-hallucination-check)を参考にしてください。
- **法律や契約にかかわる表現は、必ず人が確認する**：「無料」「業界No.1」「返金保証」のような広告の言葉、契約の条件、個人情報の扱いなどは、AIの採点で5点でも、担当部署や専門家に確認してから出しましょう。
- **社外に出す前の最後のひと目は人が見る**：プレスリリースや全顧客へのお知らせなど、出したあとに取り消せない文書は、AIで仕上げたあとも上司や担当者の確認を通してください。
- **個人情報や社外秘の情報は入れない**：お客様の名前や未発表の情報を含む文書は、会社で使ってよいと決められたAIツールだけで扱いましょう。
